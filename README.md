# PhotoSort 项目需求文档

仓库地址：[https://github.com/437180766-afk/PhotoSort](https://github.com/437180766-afk/PhotoSort)

## 项目概述

开发一款相册智能整理工具，**面向安卓手机**，打包生成 APK；支持本地离线运行、离线 OCR 识别，图片全程不上传到云端，用于自动对手机相册照片进行归类整理。

## 核心功能需求

1. 相册扫描
   - 读取安卓本机相册图片，读取图片 EXIF 信息：拍摄时间、相机型号、GPS 坐标、宽高等
   - 支持遍历相册图片资源
2. 自动分类规则（无大模型，仅依靠：EXIF 元数据 + 像素特征 + 离线 OCR 关键词正则匹配）
预设分类标签：
   - 票据类：增值税发票、发票、税号、小写、收款、付款、小票、微信支付、支付宝、订单、收据
   - 证件类：身份证、公民身份号码、驾驶证、银行卡、卡号、姓名、民族、住址
   - 医疗类：化验单、检验报告、CT、X 光、血常规、肝功能、病历、处方、药品
   - 文档类：纸质资料拍照、手写笔记、附件、页码、说明、合同
   - 生活类：美食、风景、宠物、人像自拍（兜底分类）
   - 屏幕截图类：聊天截图、验证码、APP 截图
   - 分类优先级：票据 > 证件 > 医疗 > 文档 > 生活类；截图单独优先判定
3. 出游分组
   - 使用 DBSCAN 算法，依据图片【拍摄时间 + GPS】自动聚类，生成出游分组（例如：2026-10-29 出游组）
4. 待清理照片识别（仅标记，禁止自动删除原图）
   - MD5 哈希：完全重复图片
   - 像素规则：过小图片、全黑 / 纯白废片
5. 人工修正能力
   - 支持手动修改单张图片的分类标签
6. 相册导出 / 归类操作
   - 仅**复制图片副本**到相册新建相簿，不默认移动原图，防止原图丢失
7. OCR 要求
   - 完全离线 OCR，不调用任何第三方付费云端接口；使用 PaddleOCR WASM 内置模型
8. 部署产出
   - uni-app 项目源码，可以在 HBuilderX 打开，支持云打包生成安卓 APK 安装包
   - 配套 README.md，写明环境、安装、运行、打包、权限说明
   - 配套 .gitignore 文件

## 非功能 & 约束要求

1. 运行平台：优先安卓；本版本不做 iOS 适配（iOS 相册权限限制）
2. 隐私约束：所有图片数据、OCR 识别、分类计算全部在手机本地完成，不上传网络
3. 代码要求：MVP 版本稳定，无致命 bug；业务逻辑和之前 Electron 桌面版规则保持一致
4. 仓库：代码提交至 [https://github.com/437180766-afk/PhotoSort](https://github.com/437180766-afk/PhotoSort)
5. 模型说明：PaddleOCR 中文轻量模型（det、rec、keys 文件）需要单独下载放入 static/ocr

## 页面流程

1. 首页：扫描相册、启动离线自动分类
2. 预览页：展示全部图片、自动识别标签、出游分组、待清理标记、手动修改标签
3. 导出页：一键复制图片到相册对应分类相簿
